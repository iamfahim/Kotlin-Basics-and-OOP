# Kotlin-Basics-and-OOP

Welcome to **Kotlin-Basics-and-OOP**!  
This repository is designed for novices who are starting to learn the Kotlin programming language, with a special focus on both Kotlin fundamentals and Object-Oriented Programming (OOP) concepts.

---

## 📚 Repository Structure

- [`1 Fundamentals/`](./1%20Fundamentals/):  
  Learn the basics of Kotlin, including syntax, variables, data types, control flow, functions, and more.

- [`2 ObjectOrientedProgramming/`](./2%20ObjectOrientedProgramming/):  
  Dive into OOP concepts in Kotlin, such as classes, objects, inheritance, interfaces, polymorphism, encapsulation, and abstraction.

---

## 🚀 Getting Started

1. **Clone this repository**
   ```bash
   git clone https://github.com/iamfahim/Kotlin-Basics-and-OOP.git
   ```

2. **Explore the folders**  
   Start with the `1 Fundamentals` directory before moving to `2 ObjectOrientedProgramming`.

3. **Run the code**  
   You can use IntelliJ IDEA, Android Studio, or any Kotlin-compatible IDE to run and experiment with the examples.

---

## 📝 Who is this for?

- Beginners with little or no experience in Kotlin
- Developers transitioning from other languages to Kotlin
- Anyone who wants a quick refresher on Kotlin basics and OOP principles

---

## 📦 Topics Covered

- **Kotlin Fundamentals:**  
  Variables, data types, operators, control structures, functions, and more.
- **Object-Oriented Programming:**  
  Classes & objects, constructors, inheritance, interfaces, abstract classes, encapsulation, and polymorphism.
